# 🩺 Dr AI Agent - Autonomous Medical AI Agent

Dr AI Agent is a production-style AI-powered healthcare assistant built using FastAPI, LangChain, Ollama, PostgreSQL, and Qdrant.

The goal of this project is to simulate structured doctor-like conversations while maintaining patient context, retrieving trusted medical knowledge, and following AI safety practices.

---

## 🚀 Tech Stack

- Python
- FastAPI
- Pydantic
- LangChain *(Upcoming)*
- LangGraph *(Upcoming)*
- Ollama *(Upcoming)*
- PostgreSQL *(Upcoming)*
